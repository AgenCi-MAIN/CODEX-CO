# CODEX-CO

Public reference notes on AI/ML concepts and role-aware portal design.

The [2026-08-18 conversation summary](ROOT_CHAT_LOG_2026-08-18.md) records design
ideas and study material. It is not a running application or an authoritative
record of current account permissions. Person-specific access mappings are omitted
from the current version.

## Ten Agents, Ten Portraits

The [illustrated article](index.html) presents Old HQ's ten-agent workflow for
producing a coherent collection of ten AI-made profile pictures. It is a static,
dependency-free planning article; it does not run agents, publish images, or mint
anything.

To view it locally, open `index.html` in a browser or run:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
